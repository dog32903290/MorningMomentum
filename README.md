# Morning Momentum 🌅
### 高質感 Mac 智能伴眠與喚醒系統

Morning Momentum 是一款專為 Mac 使用者打造的晨間動力工具。結合了極致的「明亮系毛玻璃 (Light Glassmorphism)」視覺美學與底層硬體自動化技術，確保你在自律的路上既有質感又絕不失誤。

## ✨ 特色功能
*   **視覺美學**：沉浸式雜誌排版風格，搭配名家座右銘，為你的早晨注入靈魂。
*   **底層喚醒 (Auto Wake)**：透過系統級 `pmset` 排程，即使 Mac 進入睡眠，也會在響鈴前 1 分鐘自動預熱喚醒。
*   **鎖定畫面播放 (Lock-screen Reliable)**：改用 macOS 原生 `afplay` 引擎，無視瀏覽器限制，鎖定畫面下依然準時鳴放。
*   **無縫授權**：只需在網頁輸入一次密碼，後台將自動處理所有底層權限，享受零干擾體驗。
*   **一鍵同步**：計畫表可直接同步至 Mac 內建「提醒事項 (Reminders)」。

## 🚀 快速開始 (安裝指南)

### 1. 必要環境
本工具需在 macOS 系統下運行，並安裝以下必要組件：
*   **Python 3.x**
*   **Flask** (`pip install flask flask-cors`)
*   **switchaudio-osx** (用於切換輸出裝置，建議安裝：`brew install switchaudio-osx`)

### 2. 啟動方式
1.  下載並解壓縮此專案。
2.  在終端機進入專案目錄，執行：
    ```bash
    python3 app.py
    ```
3.  打開瀏覽器訪問：`http://127.0.0.1:5001`

### 3. 初次設定
1.  點擊右上角 **⚙️ 設定** 圖示。
2.  選取一個你想聽的 **音樂檔案** (MP3/WAV/M4A)。
3.  開啟 **「⚡️ 喚醒睡眠中的 Mac」** 開關。
4.  在彈出的網頁對話框中輸入你的 **Mac 登入密碼** (此密碼僅儲存於你本地的專案目錄，用於執行系統授權)。

## 📁 專案結構
*   `app.py`: 後台 Flask 伺服器，負責硬體控制與 API。
*   `index.html`: 前端 UI 介面。
*   `keep_awake.sh`: 手動防休眠腳本。
*   `photo_resource/`: 存放主視覺圖片。

## 🔒 隱私與安全
*   **本地儲存**：所有的設定與密碼皆儲存在本地的 `config.json` 中，絕不上傳雲端。
*   **靜默授權**：使用 Unix `sudo -S` 機制，僅在本地執行，提供最流暢的使用體驗。
